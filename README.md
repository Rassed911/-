🚀 Marketing Campaign Predictor: End-to-End ML Service.

Этот проект представляет собой полноценный микросервисный продукт для предсказания отклика клиентов на маркетинговые кампании. 
Система не просто выдает прогноз, но и объясняет, какие факторы больше всего повлияли на решение модели.

🏗️ Архитектура проекта:
Проект реализован на базе микросервисной архитектуры и полностью контейнеризирован:
-Backend (FastAPI): Высокопроизводительный API на Python, который загружает обученную модель CatBoost и выполняет расчеты.
-Frontend (Streamlit): Интерактивный веб-интерфейс для ввода данных и визуализации результатов.
-Database (SQLite/SQL): Используется для хранения и первичной выгрузки данных для обучения.
-Docker Compose: Оркестрация сервисов, позволяющая развернуть всю систему одной командой.

🛠️ Технологический стек: 
-ML: CatBoost (Gradient Boosting), Scikit-learn, Pandas, NumPy.
-API: FastAPI, Pydantic, Uvicorn.
-UI: Streamlit.
-DevOps: Docker, Docker Compose.
-Analytics: Feature Importance (XAI) для интерпретации прогнозов.

📈 Ключевые возможности:
1.Интеллектуальный прогноз: Предсказание вероятности участия клиента в акции с учетом дисбаланса классов.
2.Объяснимый ИИ (Explainable AI): Визуализация вклада каждого признака (доход, возраст, траты) в конкретный прогноз в реальном времени.
3.Валидация данных: Строгая проверка входных типов данных через Pydantic-схемы.
4.Полная изоляция: Благодаря Docker проект запускается на любой ОС без конфликтов зависимостей.

🚀 Как запустить: 
Убедитесь, что у вас установлен Docker и Docker Compose.
1.Клонируйте репозиторий: 
git clone https://github.com/Rassed911/Marketing_Campaign_Predictor
cd marketing-campaign-predictor
2.Запустите проект:
docker-compose up --build
3.Откройте сервисы в браузере:
Интерфейс пользователя: http://localhost:8501 
Документация API (Swagger): http://localhost:8000/docs

📊 Исследовательский анализ (Insights):
В ходе разработки были выявлены важные закономерности:
-Наличие детей значительно снижает вероятность покупки премиальных товаров (вино).
-Наиболее значимыми признаками для модели оказались Total_Spending и Income.
-Клиенты, совершившие покупку недавно (Recency), более склонны к участию в новых кампаниях.
